# ADR-001: 기술 스택과 저장소 역할 분리

- 상태: 채택
- 날짜: 2026-11-10

## 결정
| 저장소 | 담당 데이터 | 이유 |
|---|---|---|
| PostgreSQL | 회원, 문서 메타데이터, 멤버 권한 | 관계와 무결성 제약이 중요한 데이터 |
| MongoDB | 페이지·요소 트리, 스토리지 메타데이터 | 깊고 자주 바뀌는 구조를 문서 단위로 저장 |
| Redis | 캐시, Refresh Token·로그아웃 블랙리스트, 문서별 접속자 | 빠른 읽기와 TTL |

## 메모
JWT 를 쓰므로 서버 세션은 두지 않는다. "Redis 세션 관리"는 토큰 저장·폐기로 해석한다.
